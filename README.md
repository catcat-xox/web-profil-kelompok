# Website Profil Kelompok

## Deskripsi
Website sederhana untuk memperkenalkan anggota kelompok
dalam tugas mata kuliah Open Source.

## Fitur
- Informasi kelompok
- Profil anggota
- Tampilan responsif

## Teknologi
- HTML5
- CSS3

## Cara Menjalankan
1. Clone repository.
2. Buka folder proyek.
3. Buka index.html melalui browser.
